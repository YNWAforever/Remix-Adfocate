# One Adfocate — Phase 1 Unification — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fold the `refreshing-adfocate` marketing site (8 public pages) into the live `adfocate-2` creator app as one bilingual product — public marketing front-of-house outside the auth gate, the live earn-loop behind login — with a working contact-lead funnel and SEO.

**Architecture:** Marketing pages mount as a pathless public layout group `_site` at the repo root, *outside* the auth-gated `_app` group. A single ported i18n provider (React Context + `localStorage`) wraps the whole tree in `__root.tsx`, serving both surfaces from one en/zh dictionary. The existing custom design system (`styles.css`) is shared verbatim — the two repos' stylesheets are byte-identical except one token — so ported pages theme correctly with no CSS changes. SEO is met with TanStack Router `head()` meta + `<HeadContent/>` plus a build-time Playwright prerender of the public routes (no SSR runtime). A new public Hono `/api/contact` route writes leads via the service-role client.

**Tech Stack:** TanStack Router v1.168 (file-based, client SPA, `tsr generate` codegen) · Vite 5 + Tailwind v4 (CSS `@theme`) · React 19 · Hono `/api` on Vercel · Supabase (Postgres + RLS) · Vitest (jsdom + integration) · npm.

**Spec:** [`docs/superpowers/specs/2026-06-20-one-adfocate-unification-design.md`](../specs/2026-06-20-one-adfocate-unification-design.md)

**Branch:** `feat/one-adfocate-unification` (already created off `main` @ `c59b516`; spec committed `c749bae`). All work commits onto this branch. Sub-slices 1A/1B/1C are intended to land as three PRs in order, but this is one plan.

## Pre-flight & conventions (read once before Task 1)

- **All paths are relative to `adfocate-2/`** unless they start with `refreshing-adfocate/`. The working directory for every command below is `adfocate-2/`.
- **Codegen:** `src/routeTree.gen.ts` is generated by `tsr generate`. NEVER hand-edit it. After adding/removing/renaming any `src/routes/*.tsx` file, run `npm run type-check` (which runs `tsr generate && tsc --noEmit`) so the tree and types regenerate. A bare `tsc` will fail on a stale tree.
- **ESM `.js` rule (prior prod outage):** every relative import in `server/` and `api/` MUST carry an explicit `.js` extension (e.g. `import { serviceClient } from "../lib/supabase.js"`). `npm run check:esm` enforces this and runs in the build. This applies ONLY to `server/`+`api/`; `src/` (Vite) imports stay extensionless.
- **Commands:**
  - Unit + component tests: `npm run test` (vitest, jsdom).
  - Integration tests (need local Supabase at `127.0.0.1:54321` + `.env.test.local`): `npm run test:integration`. Run a single integration file with `RUN_INTEGRATION=1 npx vitest run --no-file-parallelism server/test/<file>.test.ts`.
  - Full gate: `npm run check:esm && npm run type-check && npm run lint && npm run test && npm run build`.
- **`.env.local` holds PROD Supabase creds — never `source` it for tests.** Integration tests read `.env.test.local` (local stack). If that file/stack is absent, integration suites SKIP (they don't fail); the plan notes where that matters.
- **Migrations:** local dev applies via `supabase db push`/`supabase migration up` against the local stack. PROD apply is **user-gated and happens only after merge** (per the team's deploy-before-migrate incident rule — see [[adfocate-latest-state-and-prod-migration-gap]]). Tasks here apply only to the local stack.
- **Commit cadence:** one commit per task (the final step of each task). Conventional-commit messages. Never commit to `main`.
- **Locale codes:** the ported i18n uses `'en' | 'zh'` (matching the marketing source). `'zh'` renders Traditional Chinese (zh-HK copy). Default locale is `'zh'` (the app's HK audience); English visitors toggle.
- **Brand:** wordmark is **"Adfocate"** (never "ADFOCATE 2.0"). "KOCmax" is the creator-product label used contextually inside app copy, not a chrome wordmark.

## Task 1A-3: the i18n provider (with interpolation)

**Files:**
- Create: `src/lib/i18n.tsx`

- [ ] **Step 1: Write the provider**

`src/lib/i18n.tsx`:
```tsx
import {
  createContext,
  useContext,
  useEffect,
  useMemo,
  useState,
  type ReactNode,
} from "react";
import { dict, type Locale } from "./i18n.dict";

const STORAGE_KEY = "lang";

function detectInitial(): Locale {
  if (typeof window === "undefined") return "zh";
  const saved = window.localStorage.getItem(STORAGE_KEY);
  if (saved === "en" || saved === "zh") return saved;
  const nav = window.navigator.language?.toLowerCase() ?? "";
  return nav.startsWith("en") ? "en" : "zh"; // HK audience default
}

function interpolate(s: string, params?: Record<string, string | number>): string {
  if (!params) return s;
  return s.replace(/\{(\w+)\}/g, (_, k: string) => (k in params ? String(params[k]) : `{${k}}`));
}

type Ctx = {
  lang: Locale;
  setLang: (l: Locale) => void;
  t: (key: string, params?: Record<string, string | number>) => string;
};

const I18nCtx = createContext<Ctx>({
  lang: "zh",
  setLang: () => {},
  t: (k) => String(k),
});

export function I18nProvider({ children }: { children: ReactNode }) {
  const [lang, setLangState] = useState<Locale>("zh");

  // Resolve the real initial locale after mount (avoids SSR/prerender mismatch).
  useEffect(() => {
    setLangState(detectInitial());
  }, []);

  const value = useMemo<Ctx>(
    () => ({
      lang,
      setLang: (l) => {
        setLangState(l);
        if (typeof window !== "undefined") window.localStorage.setItem(STORAGE_KEY, l);
      },
      t: (key, params) => interpolate(dict[lang][key] ?? dict.en[key] ?? key, params),
    }),
    [lang],
  );

  return <I18nCtx.Provider value={value}>{children}</I18nCtx.Provider>;
}

export const useI18n = () => useContext(I18nCtx);
```

```tsx
/** Compact en/zh switch. Shows the language it will switch TO. */

    <button
      type="button"

      }
    >
      {lang === "en" ? "中" : "EN"}

}
```

```ts
import { Hono } from "hono";
import type { Env } from "../types.js"; // mirror the import used by server/routes/public.ts
import { serviceClient } from "../lib/supabase.js";

const LEAD_TYPES = [
  "brand_enquiry",
  "creator_signup",
  "adfoplace_offer",
  "capital_waitlist",
  "partner_enquiry",
] as const;
type LeadType = (typeof LEAD_TYPES)[number];

// Best-effort per-instance rate limit (serverless: per warm instance only).
const hits = new Map<string, { count: number; ts: number }>();
const WINDOW_MS = 60_000;
const MAX = 5;
function rateLimited(ip: string): boolean {
  const now = Date.now();
  const cur = hits.get(ip);
  if (!cur || now - cur.ts > WINDOW_MS) {
    hits.set(ip, { count: 1, ts: now });
    return false;
  }
  cur.count += 1;
  return cur.count > MAX;
}

const EMAIL_RE = /^[^@\s]+@[^@\s]+\.[^@\s]+$/;

export const contactRoutes = new Hono<Env>();

contactRoutes.post("/", async (c) => {
  const ip = c.req.header("x-forwarded-for")?.split(",")[0]?.trim() || "unknown";
  if (rateLimited(ip)) return c.json({ error: "Too many requests", code: "rate_limited" }, 429);

  const body = await c.req
    .json<{
      type?: string;
      name?: string;
      email?: string;
      message?: string;
      payload?: Record<string, unknown>;
      locale?: string;
    }>()
    .catch(() => null);
  if (!body) return c.json({ error: "Invalid JSON", code: "bad_request" }, 400);

  if (!body.type || !LEAD_TYPES.includes(body.type as LeadType)) {
    return c.json({ error: "Invalid enquiry type", code: "bad_type" }, 400);
  }
  if (!body.name?.trim()) return c.json({ error: "Name required", code: "no_name" }, 400);
  if (!body.email?.trim() || !EMAIL_RE.test(body.email.trim())) {
    return c.json({ error: "Valid email required", code: "bad_email" }, 400);
  }

  const svc = serviceClient();
  const { error } = await svc.from("leads").insert({
    type: body.type,
    name: body.name.trim(),
    email: body.email.trim(),
    message: body.message?.trim() || null,
    payload: body.payload ?? {},
    locale: body.locale === "en" ? "en" : "zh-HK",
  });
  if (error) return c.json({ error: error.message, code: "db_error" }, 500);
  return c.json({ ok: true }, 201);
});
```

## Task 1C-6: build-time prerender (SSG) of public routes

Pure client SPA → snapshot the public routes to static HTML after `vite build`, using a headless Chromium crawl of `vite preview`. This is the lowest-friction approach for TanStack Router (no SSR entry needed) and `head()` meta is captured into the static HTML. `head()` meta (1C-1) already gives JS-executing crawlers correct titles, so SEO degrades gracefully if prerender is skipped.

**Files:**
- Create: `scripts/prerender.mjs`
- Modify: `package.json` (deps + `build`)

- [ ] **Step 1: Add Playwright (chromium only)**

Run: `npm install -D playwright` then `npx playwright install chromium`
Expected: installed.

- [ ] **Step 2: Write the prerender script** — `scripts/prerender.mjs`:
```js
import { spawn } from "node:child_process";
import { mkdir, writeFile, readFile } from "node:fs/promises";
import { dirname, join } from "node:path";
import { chromium } from "playwright";

const PORT = 4173;
const BASE = `http://127.0.0.1:${PORT}`;
const ROUTES = [
  "/", "/creators", "/brands", "/packages", "/earn",
  "/stories", "/playbooks", "/contact", "/legal/terms", "/legal/privacy",
];

function waitForServer(url, tries = 40) {
  return new Promise((resolve, reject) => {
    const attempt = async (n) => {
      try {
        const r = await fetch(url);
        if (r.ok) return resolve();
      } catch {}
      if (n <= 0) return reject(new Error("preview server did not start"));
      setTimeout(() => attempt(n - 1), 250);
    };
    attempt(tries);
  });
}

const preview = spawn("npx", ["vite", "preview", "--port", String(PORT), "--strictPort"], {
  stdio: "inherit",
});

try {
  await waitForServer(BASE + "/");
  const browser = await chromium.launch();
  const page = await browser.newPage();
  for (const route of ROUTES) {
    await page.goto(BASE + route, { waitUntil: "networkidle" });
    await page.waitForSelector("#main, main", { timeout: 10_000 }).catch(() => {});
    const html = await page.content();
    const outPath = route === "/" ? "dist/index.html" : join("dist", route.slice(1), "index.html");
    await mkdir(dirname(outPath), { recursive: true });
    await writeFile(outPath, html, "utf8");
    console.log("prerendered", route, "->", outPath);
  }
  await browser.close();
  // sanity: the home snapshot must contain the brand title
  const home = await readFile("dist/index.html", "utf8");
  if (!/Adfocate/.test(home)) throw new Error("prerendered home missing brand title");
} finally {
  preview.kill("SIGTERM");
}
```
