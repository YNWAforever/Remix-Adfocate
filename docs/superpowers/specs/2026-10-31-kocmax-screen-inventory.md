## 完整示例流程

公開首頁 → 任務預覽 → onboarding／consent → 範本 → 對話 → 證據 → 私人 Brief → 排除私人來源 → 分享確認 → 原任務提交 → reviewer 批准發佈 → 創作者提交證明 → reviewer 核實 → operator 完成確認 → admin 結算 → 600 積分與徽章 → 500 積分兌換。

原型中切換到下一個角色畫面不會自動執行審批；需按該角色的確認動作。示例初始 420 積分／620 XP；任務 +180 積分、0 XP；兌換後 100 積分。

## 尚需正式工程驗收

本機原型版面／互動檢查紀錄另見 verification 文件。正式版仍需真實 session、資料權限、可存取性工具、實機鍵盤／讀屏、完整英語、內容長度與大量資料驗收。
