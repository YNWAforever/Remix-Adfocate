## 尚未清除的界線

1. 創作者條款門檻保留；九帳戶測試沒有接受法律條款，故門檻後的創作者操作、接任務獎勵、兌換和報告流程未作真實驗收。
2. 原 D1 方案要求獨立 DB／Auth／Storage 與託管試點；使用者後來明確選擇現有 `Remix-Adfocate` 資料庫。本輪驗證只支持**共用資料庫的權限切片**，不能宣稱原隔離環境條件已滿足。
3. 沒有驗證 refresh token 清理後的重播拒絕，也沒有清理後重登入：九個測試帳戶已封鎖。實際 provider revoke、hosted callback／保護／日誌、持久憑證與排程仍未驗證。
4. 畫面仍有四項已記錄的介面問題：operator 直達編輯頁仍見寫入控制項、品牌 member 見刪除按鈕、一次登出畫面直到 reload 才更新、密碼登入的拒絕文案誤稱 Google 帳戶。伺服器權限拒絕已通過；這些畫面項目仍需分別修正與回歸，詳見[執行報告](auth-permission-execution/EXECUTION-RESULTS-20261102.md)。
5. Instagram IG-01／IG-02 仍阻斷，IG-03 待官方產品對照，IG-04 帳戶資格未驗證；Google Drive 也未授權。見[阻斷清單](instagram-blockers.md)與[權限界線](permissions.md)。
